# SimRecSign

#### Description
> **简录签 SimRecSign** 是一个电子签署与流程审批系统：把纸质表单变成 PDF 电子模板，配置字段与多步签署流程后在线流转，最终生成带数字签名与防篡改审计记录的 PDF 文档。支持 PC 管理端与手机端（H5）双入口。
